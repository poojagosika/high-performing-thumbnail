# High-Performing Thumbnail

Design YouTube thumbnails by learning from the ones that already work.

Type a video title and tags, browse the top-performing thumbnails for that topic, and pick one as a reference. The app reads the reference's design and rebuilds it with your own photos and headline. It copies the layout, font, highlight style, text colour and position. It never reuses another creator's images.

Everything runs on your own server with small in-house models. No paid image or AI APIs are needed.

## How it works

1. **Research.** Search by title and tags. Results come from the YouTube Data API and are ranked by performance. Without an API key the app falls back to built-in sample results.
2. **Read the reference.** A Python worker analyses the chosen thumbnail:
   - **Faces and text:** detected with OpenCV DNN models (YuNet and PP-OCR).
   - **Layout:** one of eight templates, such as two subjects, host and headline, three panels or split screen.
   - **Font:** a font reader classifies 17 bundled fonts letter by letter.
   - **Highlights:** an emphasis reader finds up to two highlighted lines (coloured, boxed, circled or gradient words) and their colours.
   - **Text colour and outline:** read by an ink reader.
   - **Headline size, side and height:** measured from the detected text.
3. **Plan.** The planner turns that reading into a headline design for your title. It balances line breaks, pairs fonts and applies the highlights, colours, size and position.
4. **Compose.** Your photos are cut out (background removal with rembg), colour-graded to the reference's mood, and layered with the headline using sharp.
5. **Adjust.** A "Copied from reference" strip shows everything that was read, with a switch for each part. Turning a switch off rebuilds the thumbnail without that part, keeping your edited words and slot-editor tweaks.

## Tech stack

| Part | Tools |
| --- | --- |
| Client | React 19, Vite, Tailwind, Framer Motion |
| Server | Node.js, Express, MongoDB with Mongoose, sharp |
| Image analysis | Python, OpenCV, NumPy, rembg |
| Models | ONNX face and text detectors, plus three small NumPy models trained in this repo (font, emphasis, ink) |

## Getting started

### Requirements

- Node.js 22
- Python 3.11
- MongoDB (local or hosted)

### Install

```bash
npm install
npm run install:all
pip install -r server/requirements.txt
```

### Configure

Copy the example env files and fill in the values:

```bash
cp server/.env.example server/.env
cp client/.env.example client/.env
```

| Variable | Needed for |
| --- | --- |
| `MONGODB_URI` | Database (required) |
| `JWT_SECRET` | Sign-in tokens (required, at least 32 characters) |
| `CLIENT_URL`, `CORS_ORIGINS` | Allowing the client to call the server |
| `YOUTUBE_API_KEY` | Live search results (optional; sample results are used without it) |
| `TURNSTILE_SECRET_KEY`, `VITE_TURNSTILE_SITE_KEY` | Bot protection on sign-up and sign-in (required in production) |
| `RESEND_API_KEY`, `MAIL_FROM` | Password reset and other emails (optional) |
| `VITE_API_URL` | Server address for the client, for example `http://localhost:5000/api` |

Generate a JWT secret with:

```bash
node -e "console.log(require('crypto').randomBytes(48).toString('hex'))"
```

### Run

```bash
npm run dev
```

This starts the server on port 5000 and the client on port 5173.

## Tests

```bash
cd server
npm test
```

The suite covers the API, planner, renderer, compositor and readers. The reader tests need the Python packages from `server/requirements.txt`. CI runs these tests and the client lint and build on every push to `develop` and every pull request to `main`.

```
  assets/

    models/             Detector and reader model files
  test/                 Test suites
```

## Retraining the models

The font, emphasis and ink readers are trained on thumbnails generated by the app's own renderer, so no external dataset is needed.

```bash
cd server
python3 ml/train_fonts.py

OUT=/tmp/emphasis-train COUNT=700 SEED=1 node ml/make_emphasis_data.js
OUT=/tmp/emphasis-test COUNT=500 SEED=99 node ml/make_emphasis_data.js
python3 ml/train_emphasis.py /tmp/emphasis-train /tmp/emphasis-test
python3 ml/train_ink.py /tmp/emphasis-train /tmp/emphasis-test
```

Set `PHOTOS` to a comma-separated list of image paths to use real photos as backgrounds in the generated data. The trained models are saved to `server/assets/models/`.
